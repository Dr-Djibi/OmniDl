# OmniDL 📥

OmniDL est une application mobile puissante et élégante, développée en React Native / Expo, permettant de télécharger rapidement et facilement des médias (vidéos et musiques). Elle fonctionne en synergie avec une API backend dédiée et l'écosystème du bot MENMA_MD.

## ✨ Fonctionnalités
- **Détection Intelligente** : Détecte automatiquement les liens copiés dans le presse-papier dès l'ouverture de l'application.
- **Dossiers Personnalisés** : Sauvegarde native des fichiers directement dans les répertoires de votre téléphone (ex: `Téléchargements/OmniDL`) grâce à l'intégration du Storage Access Framework (SAF) d'Android.
- **Gestionnaire de Médias** : Historique complet des téléchargements, tri des fichiers (vidéos/audios), suivi de l'espace de stockage et nettoyage de cache.
- **Interface Moderne** : Design soigné avec un thème sombre natif (Obsidian Stream).
- **Compilation Automatisée** : Pipeline d'intégration GitHub Actions configuré pour générer des fichiers `.apk` à chaque mise à jour.

## 🚀 Installation de l'application
Vous pouvez télécharger la dernière version de l'application (APK) directement depuis l'onglet [Actions](../../actions) de ce dépôt GitHub.
Cliquez sur le dernier build réussi et téléchargez le fichier `OmniDL-App-Android.zip` en bas de page.
